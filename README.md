# Powerbi-Project-
Global EV Sales 
Global EV Sales & Adoption Analysis | Power BI
An interactive Power BI dashboard project exploring global electric vehicle (EV) adoption, sales, stock, and market trends. The report uses the IEA Global EV Data 2024 dataset to compare regions, vehicle categories, powertrains, and changes over time.
Project Overview
The transition to electric mobility produces large amounts of data across countries, vehicle types, and powertrains. This project turns that data into interactive visualizations to make trends and regional differences easier to understand.

The analysis covers historical data from 2010–2023, with projections extending to 2035 where available in the dataset.
Objectives
- Explore global EV adoption and sales trends over time.
- Compare EV performance across regions and vehicle categories.
- Analyze powertrain-related patterns and other EV indicators.
- Use parameter and unit analysis to examine the data from different perspectives.
- Present findings through clear, interactive Power BI visuals.
- Develop insights that can inform discussions about policy, investment, and the transition to electric mobility.
Tools & Technologies
- Microsoft Power BI Desktop — dashboard development and data visualization
- DAX — measures and calculations, where used in the report
- Power Query — data preparation and transformation, where used
- CSV dataset — IEA Global EV Data 2024
Dashboard Pages
The report is organized into the following sections:
- Regional & Category Trends — compare EV trends across regions and categories.
- Powertrain & More Insights — explore powertrain-related trends and additional indicators.
- Parameter & Unit Analysis — examine measures using different parameters and units.
- Time Series & Comparative Analysis — review changes over time and compare trends.
- Key Insights — summarize the main observations from the analysis.
- Conclusion & Recommendations — communicate the overall takeaways and possible next steps.
The report also includes introductory pages describing the business problem, problem statement, objectives, and dataset column descriptions.
Business Questions
This project is designed to help explore questions such as:
1. How have EV adoption and sales changed over time?
2. Which regions show different levels or patterns of EV adoption?
3. How do EV trends vary by vehicle category and powertrain?
4. What changes are visible across the available time periods and indicators?
5. What insights can be drawn from comparing regions, categories, and time-series data?
How to View the Project
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop if it is not already installed.
3. Open powerbi_project.pbix in Power BI Desktop.
4. Use the report page tabs and interactive visuals to explore the analysis.
